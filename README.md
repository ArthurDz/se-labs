# se-labs

Учебный проект по дисциплине **«Программная инженерия»**.

Практические работы курса изначально описаны для Microsoft Azure DevOps. В этом проекте они выполняются средствами GitHub.

| Azure DevOps | GitHub |
|---|---|
| Организация | GitHub Organization |
| Boards | GitHub Projects, Issues |
| Repos | Репозитории |
| Wiki | GitHub Wiki |
| Pipelines | GitHub Actions |
| Artifacts | GitHub Packages, артефакты Actions |
